☁ 雲端同步與備份
用 GitHub Gist 在手機、電腦之間同步進度。每次開啟會先讀取雲端最新進度，Token 失效時不讀取，只用本機進度。
換新 Token：直接貼上新的再按「儲存」，這支手機的進度會合併進雲端（同一個 GitHub 帳號會自動找到原本的雲端檔案）。Token 只存在這個瀏覽器，不會寫進網站程式碼。
建立方式：GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)，只勾 gist。
顏色：灰＝還沒練過　紅＝剛答錯　橘＝剛開始記　黃＝快記住　綠＝熟了　虛線框＝今天該複習。點格子可聽發音。
點任一個字開始練習，也可以隨機連續練習。純練習，不計入熟練度。
